# BILET — Téléchargements officiels

Bienvenue sur la plateforme officielle de téléchargement des applications BILET.

## BILET Hospitality V2.4.0

Solution de gestion hôtelière disponible pour Windows et Android.

### Téléchargements

* [Télécharger pour Windows](https://github.com/rattawa2012-dotcom/bilet-telechargements/releases/download/hospitality-v2.4.0/BILET_Hospitality_V2.4.0_Setup.exe)
* [Télécharger pour Android](https://github.com/rattawa2012-dotcom/bilet-telechargements/releases/download/hospitality-v2.4.0/BILET_Hospitality_V2.4.0_Android.apk)

### Licence

BILET Hospitality nécessite une licence d’utilisation liée à l’appareil. Une période d’essai de 30 jours est disponible lors de la première utilisation.

Pour obtenir ou renouveler une licence, contactez l’assistance BILET.

### Installation Windows

1. Téléchargez le fichier `BILET_Hospitality_V2.4.0_Setup.exe`.
2. Ouvrez le fichier téléchargé.
3. Suivez les étapes d’installation.
4. Lancez BILET Hospitality depuis le raccourci du Bureau.

### Installation Android

1. Téléchargez le fichier `BILET_Hospitality_V2.4.0_Android.apk`.
2. Ouvrez le fichier sur votre appareil Android.
3. Autorisez l’installation depuis cette source si Android le demande.
4. Terminez l’installation et ouvrez l’application.
